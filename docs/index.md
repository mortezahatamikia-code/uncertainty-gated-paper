# دانشنامه و نقشه راه جامع مستندات فنی و علمی BioDINO-Edge
### (Master Documentation Index & Step-by-Step Curriculum)

> **خوش آمدید!**  
> این سند، **نقشه راه و راهنمای مرکزی (Master Index)** برای تمامی مستندات پروژه پژوهشی **BioDINO-Edge** است. اگر شما به تازگی با این مخزن آشنا شده‌اید و می‌خواهید از صفر تا صدِ مبانی تئوریک، خط‌به‌خط کدها، ریاضیات، پاتولوژی گیاهی، استقرار سخت‌افزاری و فنون دفاع در برابر داوران بین‌المللی را فرا گیرید، این صفحه نقشه راه گام‌به‌گام شماست.

## ۲. اطلس جامع مکان‌یابی فایل‌ها و اجزای مخزن (Repository Directory Layout & Asset Atlas)

برای دسترسی فوری به هر بخش از پروژه، مکان دقیق تک‌تک فایل‌ها و نقش عملیاتی آن‌ها در ساختار زیر مدون شده است:

```text
research-few-shot/
│
├── 📁 pipeline/                                   # 🚀 پوشه ابزارهای اجرایی، پایپلاین و نوت‌بوک ۱۱ کلاسه
│   ├── biodino_edge_pipeline.py                 # پایپلاین اصلی خط فرمان (آموزش آفلاین فیشر، کالیبراسیون و ارزیابی ۱۱ کلاسه)
│   ├── biodino_unified_pipeline.ipynb            # نوت‌بوک تعاملی یکپارچه ۵ بخشی با ماتریس درهم‌ریختگی
│   ├── demo_predict.py                          # ابزار تعاملی CLI برای اسکن تک‌تصویر، تصمیم گیت شانون و چارت احتمالات
│   ├── export_edge_models.py                    # موتور اکسپورت دو سطحی به ONNX INT8 و اعتبارسنجی تاخیر
│   ├── generate_architecture_diagram.py          # اسکریپت تولید دیاگرام معماری برداری (شکل ۱ مقاله)
│   ├── generate_saliency_and_calibration.py      # اسکریپت استخراج سلف‌اتنشن و دیاگرام کالیبراسیون ECE (شکل‌های ۲ و ۳)
│   └── taxonomic_prompts.py                     # بانک پرامپت‌های گیاه‌پزشکی لاتین (سیب، انگور و سیب‌زمینی)
│
├── 🧠 biodino_mobile_int8.onnx                  # مدل مستقل سطح ۱ موبایل (۳۸۴ بعدی، ۲۲MB، تاخیر ~۲۱ms در ریشه)
├── 🧠 biodino_companion_int8.onnx               # مدل مکمل همراه سطح ۲ (۸۹۶ بعدی، ۸۵MB، دقت ۹۸.۷۲٪ در ریشه)
├── 📊 biodino_edge_results.json                  # گزارش عددی رسمی بنچمارک، ماتریس کانفیوژن و ECE
├── 📜 CHANGELOG.md                              # گاه‌شمار نسخه‌ها و رکوردهای دقت پروژه
├── 📦 datapackage.json                          # شناسنامه بسته داده باز OKF (مشخصات ۲۷ کلاس پایه و ۱۱ کلاس نوظهور)
├── 📋 requirements.txt                          # وابستگی‌های پایتون (PyTorch CUDA 12.4, timm, open_clip, onnxruntime)
├── ⚙️ pyrefly.toml                              # تنظیمات اتصال به محیط مجازی .venv
├── 📄 README.md                                 # سند اصلی معرفی پروژه، متدولوژی و دستورات اجرایی
├── 🚀 DEPLOYMENT_GUIDE.md                       # راهنمای بیلد و استقرار وب‌سایت پورتفولیو روی GitHub Pages
│
├── 📁 cache_artifacts/                          # ⚡ کَش استخراج ویژگی‌های سنگین جهت اجرای آنی زیر ۱ ثانیه
│   └── pv_novel_embeddings.pt                  # فیچرهای استخراج‌شده ۹,۳۳۰ برگ آزمون ۱۱ کلاسه (۳۵MB)
│
├── 📁 paper/                                    # 📝 پکیج کامل مقاله رسمی کنفرانس/ژورنال IEEE
│   ├── main.tex                                 # سورس کامل دو ستونه لاتک مقاله
│   ├── main.pdf                                 # فایل PDF دوربین‌خوان نهایی مقاله (۷ صفحه)
│   ├── fig_architecture.pdf / .png             # شکل ۱: معماری دو سطحی BioDINO-Edge
│   ├── fig_saliency.pdf / .png                 # شکل ۲: نقشه‌های سلف‌اتنشن و مهار چاله توجه
│   ├── fig_calibration.pdf / .png              # شکل ۳: دیاگرام قابلیت اطمینان و کالیبراسیون ۱۰ سطلی
│   ├── references.bib                           # مراجع استاندارد BibTeX
│   └── IEEEtran.cls                             # کلاس رسمی ژورنال‌های IEEE
│
├── 📁 docs/                                     # 📚 دانشنامه جامع ۱۶ گانه مستندات علمی، ریاضی و اجرایی
├── 📁 web/                                      # 🌐 پورتفولیو و وب‌سایت علمی Next.js 16 + Tailwind CSS
├── 📁 android_app/                              # 📱 اپلیکیشن نیتیو اندروید با کاتلین و Jetpack Compose
├── 📁 plantvillage/                             # 🌿 دیتاست کامل ۵۴,۳۰۵ تصویر برگ با ۳۸ کلاس
└── 📁 plantdoc/                                 # 📷 دیتاست تصاویر چالش‌برانگیز مزرعه و نور طبیعی
```
