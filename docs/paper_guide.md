# راهنمای جامع و صفر تا صد راه‌اندازی و ویرایش مقاله IEEE در Antigravity / VS Code

این راهنما برای هر کاربری که می‌خواهد این پروژه و مقاله لاتک را روی یک سیستم خام دیگر از صفر راه‌اندازی، ویرایش و کامپایل کند نوشته شده است (قدم به قدم و با فرض اینکه کاربر هیچ پیش‌زمینه‌ای ندارد).

---

## ۱. فایل‌های موجود در این پوشه (`paper/`)

در پوشه `paper` فایل‌های زیر قرار دارند:
* **`main.tex`**: فایل سورس اصلی مقاله به فرمت رسمی و دو ستونه کنفرانس IEEE (شامل چکیده، مقدمه، روابط ریاضی، جداول مقایسه نتایج و جمع‌بندی).
* **`references.bib`**: بانک اطلاعاتی مراجع و مقالات مرتبط (BibTeX) شامل مقالات CLIP, LoRA, Tip-Adapter و PlantVillage.
* **`IEEEtran.cls`**: فایل کلاس رسمی IEEE (دانلودشده از سرور رسمی CTAN) که در کنار پروژه قرار دارد تا سیستم برای پیدا کردن قالب نیازی به دانلود اضافه نداشته باشد.
* **`main.pdf`**: سند نهایی خروجی تولیدشده (کامپایل‌شده).

---

## ۲. گام‌های راه‌اندازی روی یک سیستم کامپیوتر جدید (قدم به قدم)

برای اینکه بتوانید این مقاله را باز کنید، تغییر دهید و پیش‌نمایش زنده خروجی PDF آن را ببینید، فقط ۳ مرحله زیر را طی کنید:

### گام اول: نصب اکستنشن در ادیتور (Antigravity یا VS Code)
1. نرم‌افزار **Antigravity IDE** (یا VS Code) را باز کنید.
2. از منوی سمت چپ روی آیکون **Extensions** (یا کلیدهای میانبر `Ctrl + Shift + X`) کلیک کنید.
3. در نوار جستجو نام **`LaTeX Workshop`** (شناسه: `James-Yu.latex-workshop`) را سرچ کرده و روی دکمه **Install** کلیک کنید.

---

### گام دوم: نصب کامپایلر لاتک روی سیستم‌عامل (MiKTeX)
اکستنشن لاتک صرفاً یک ویرایشگر است و برای تبدیل کدهای لاتک به فایل واقعی PDF، ویندوز به یک موتور کامپایلر نیاز دارد. بهترین و سبک‌ترین موتور برای ویندوز **MiKTeX** است.

**روش نصب سریع (از طریق PowerShell):**
یک ترمینال PowerShell در ویندوز باز کنید و دستور زیر را اجرا کنید:
```powershell
winget install MiKTeX.MiKTeX
```
*(یا می‌توانید اینستالر آن را مستقیماً از سایت رسمی [miktex.org/download](https://miktex.org/download) دانلود و نصب کنید).*

> **⚠️ یک نکته فوق‌العاده حیاتی در نصب MiKTeX:**  
> موقع نصب از شما سوالی پرسیده می‌شود:  
> *"Install missing packages on-the-fly?"*  
> حتماً آن را روی **Yes** بگذارید. این گزینه باعث می‌شود هر پکیج یا فونت جدیدی که در مقاله‌تان استفاده کنید، به‌طور خودکار در پس‌زمینه دانلود شود و هیچ‌گاه با خطای پکیج گم‌شده متوقف نشوید.

---

### گام سوم: تنظیم فایل کانفیگ `.vscode/settings.json` (رفع تمام خطاهای متداول)

در ویندوز هنگام کار با LaTeX Workshop دو مشکل معروف پیش می‌آید که در این پروژه آن‌ها را ریشه‌ای حل کردیم:

1. **خطای Perl (`MiKTeX could not find script engine perl / latexmk ENOENT`):**  
   دستور پیش‌فرض اکستنشن `latexmk` است که برای اجرا نیاز به زبان Perl دارد (که روی ویندوز نیست). ما کامپایلر را روی **`pdflatex`** تنظیم کردیم که برنامه بومی C++ ویندوز است و نیازی به هیچ زبان دیگری ندارد.
2. **خطای Formatter هنگام ذخیره (`Please set your LaTeX formatter`):**  
   با خاموش کردن فرمتر، این پیام مزاحم حذف می‌شود.

برای اینکه در هر سیستمی این تنظیمات در ۱ ثانیه اعمال شود، یک فایل با نام **`settings.json`** درون پوشه **`.vscode`** در ریشه پروژه قرار دهید با محتوای زیر:

مسیر فایل: `e:\work\research-few-shot\.vscode\settings.json`

```json
{
    "latex-workshop.latex.tools": [
        {
            "name": "pdflatex",
            "command": "C:/Users/%USERNAME%/AppData/Local/Programs/MiKTeX/miktex/bin/x64/pdflatex.exe",
            "args": [
                "-synctex=1",
                "-interaction=nonstopmode",
                "-file-line-error",
                "%DOC%"
            ],
            "env": {}
        },
        {
            "name": "bibtex",
            "command": "C:/Users/%USERNAME%/AppData/Local/Programs/MiKTeX/miktex/bin/x64/bibtex.exe",
            "args": [
                "%DOCFILE%"
            ],
            "env": {}
        }
    ],
    "latex-workshop.latex.recipes": [
        {
            "name": "pdflatex",
            "tools": [
                "pdflatex"
            ]
        },
        {
            "name": "pdflatex -> bibtex -> pdflatex*2",
            "tools": [
                "pdflatex",
                "bibtex",
                "pdflatex",
                "pdflatex"
            ]
        }
    ],
    "latex-workshop.view.pdf.viewer": "tab",
    "latex-workshop.formatting.latex": "none",
    "[latex]": {
        "editor.formatOnSave": false
    }
}
```
*(در سیستم‌های دیگر به جای `%USERNAME%` نام یوزر ویندوز قرار می‌گیرد).*

## ۳. چطور مقاله را ویرایش، کامپایل و مشاهده کنیم؟

### ۱. مشاهده زنده PDF کنار متن
1. فایل `paper/main.tex` را باز کنید.
2. کلیدهای میانبر **`Ctrl + Alt + V`** را بزنید و گزینه **View in VS Code tab** را انتخاب کنید.
3. یک تب PDF در سمت راست باز می‌شود که پیش‌نمایش زنده‌ی مقاله شماست.

### ۲. ویرایش و ذخیره
* هر کلمه یا پاراگرافی را در `main.tex` تغییر دهید و دکمه **`Ctrl + S`** را بزنید.
* اکستنشن به صورت خودکار سند را کامپایل می‌کند و تب PDF در کمتر از ۱ ثانیه رفرش می‌شود!

### ۳. ناوبری دوطرفه (SyncTeX)
* اگر کلید **`Ctrl`** را نگه دارید و روی هر کلمه‌ای در کد کلیک کنید، نشانگر در تب PDF روی همان کلمه قرار می‌گیرد.
* اگر در فایل PDF دابل کلیک کنید، نشانگر در ادیتور روی خط سورس همان پاراگراف می‌رود!

## ۴. نحوه اضافه کردن مراجع جدید (BibTeX)

1. متن ارجاع را به انتهای فایل `references.bib` اضافه کنید، مثلاً:
   ```bibtex
   @article{smith2024,
     title={Deep Learning in Agriculture},
     author={Smith, John},
     journal={IEEE Transactions on AI},
     year={2024}
   }
   ```
2. در متن مقاله هر جا خواستید ارجاع دهید بنویسید: `\cite{smith2024}`.
3. برای ساخت کامل ارجاعات، از پنل کناری `TEX` در ادیتور، روی دستور `pdflatex -> bibtex -> pdflatex*2` کلیک کنید تا شماره مراجع در مقاله به جای علامت سوال درج شوند.

## ۵. ویرایش از طریق Overleaf (اختیاری)

اگر در سفر یا روی سیستمی بودید که نرم‌افزار نداشتید و خواستید از ادیتور آنلاین استفاده کنید:
1. پوشه `paper` را Zip کنید و در سایت [Overleaf.com](https://www.overleaf.com) آپلود نمایید.
2. از قابلیت **Visual Editor** اورلیف برای ادیت دیداری متن شبیه ورد استفاده کنید.
3. هر زمان خواستید پروژه را برگردانید، از دکمه `Menu -> Download -> Source` فایل زیپ را دانلود کرده و دوباره در این پوشه جایگزین کنید.
