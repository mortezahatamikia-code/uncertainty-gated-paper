# 📋 فهرست مشخصات و نیازمندی‌ها (Specs)

این فهرست به صورت خودکار توسط **Dataview** از کل اسناد پوشه `Specs/` خوانده و به‌روزرسانی می‌شود.

```dataview
TABLE WITHOUT ID
  file.link AS "عنوان مشخصات",
  status AS "وضعیت",
  created AS "تاریخ ایجاد"
FROM "Specs" AND #spec
SORT file.name ASC
```
