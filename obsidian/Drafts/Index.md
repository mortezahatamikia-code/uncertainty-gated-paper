# 📝 فاز ۴: پیش‌نویس بخش‌های مقاله علمی (Paper Drafts)

این دایرکتوری محل تدوین و نگهداری پیش‌نویس بخش‌های مختلف مقاله جدید بر پایه کدهای اجرا شده و بنچمارک‌های فاز ۳ است (Abstract, Introduction, Related Work, Methodology, Experiments, Discussion, Conclusion).

```dataview
TABLE WITHOUT ID
  file.link AS "بخش مقاله",
  target_section AS "سکشن ژورنال",
  status AS "وضعیت نگارش",
  word_count AS "حجم تقریبی (کلمات)"
FROM "Drafts" AND #draft
SORT file.name ASC
```
