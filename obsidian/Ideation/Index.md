# 💡 فاز ۱: حوضچه ایده‌ها و فرضیات اولیه (Ideation & Hypotheses)

این مخزن برای ثبت فرضیه‌های علمی خام، الگوهای ابتکاری و ایده‌های اولیه پژوهش ایجاد شده است. 
هدف اصلی این فاز: **افزایش دقت تشخیص خودکار برگ و بیماری، بدون افزایش حجم مدل (Zero-Footprint Growth) و بدون افت سرعت استنتاج روی پردازنده لبه.**

```dataview
TABLE WITHOUT ID
  file.link AS "عنوان فرضیه / ایده",
  mechanism AS "مکانیزم پیشنهادی",
  expected_gain AS "دستاورد مورد انتظار",
  status AS "وضعیت بررسی"
FROM "Ideation" AND #idea
SORT file.name ASC
```
