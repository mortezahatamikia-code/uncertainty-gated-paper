# 🧪 فاز ۲: سوابق تصمیمات معماری (ADR) و ترکیب ایده‌ها

این بخش میزبان **سوابق تصمیمات معماری (Architectural Decision Records)** است که نتایج غربالگری ایده‌های فاز ۱، سنتز و ترکیب راهکارها، و چرایی پذیرش یا رد تکنیک‌ها (مانند حذف روتر صلب و اتخاذ روتر بیزی با نرمال‌سازی کاردینالیتی) را با شواهد تجربی ثبت می‌کند.

```dataview
TABLE WITHOUT ID
  file.link AS "شماره و عنوان ADR",
  status AS "وضعیت تصمیم (Accepted/Rejected)",
  impact AS "اثر روی دقت و سرعت",
  date AS "تاریخ تصمیم"
FROM "Architecture/ADR" AND #adr
SORT file.name ASC
```
