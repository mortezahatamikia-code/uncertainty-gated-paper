The vault is organized around a phase-driven research workflow (Ideation → Specs → Architecture/ADR → Tasks → Drafts → Reviews) with each phase in its own top-level directory (`Ideation/`, `Specs/`, `Architecture/`, `Tasks/`, `Drafts/`, `Reviews/`, `Logs/`). The entry point is `00 - Dashboard.md`, a Dataview-powered MOC that renders tables of notes by tag (`#idea`, `#adr`, `#task`, `#draft`, `#humanize`) and links to `Project Board.canvas` for the visual Kanban board. `.obsidian/app.json` configures Obsidian settings (dark theme, live preview, markdown links disabled). `.agents/skills/obsidian-graph-flow/SKILL.md` defines an autonomous agent skill that decomposes goals into this graph, drives the four-stage lifecycle (Backlog → To Do → Doing → Done), and keeps Canvas nodes and markdown wikilinks in sync. Templates under `.agents/skills/obsidian-graph-flow/templates/` standardize ADR/spec/task note shapes.
