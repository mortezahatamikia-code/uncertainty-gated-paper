The repo is a research suite rather than a single deployable system: two Python pipelines (`biodino_pipeline`, `morphopath_pipeline`) share the same foundation-model stack (DINOv2 Small + BioCLIP ViT-B fused via Fisher-LDA / shrunk LDA with Shannon-margin gating) but target different disease taxonomies (PlantVillage apple/grape/potato vs. foliar morphopath classes). The Android app consumes the INT8 ONNX model produced by the pipeline's export step (`export_edge_models.py`), forming a train→export→deploy chain across children. Published benchmark results are persisted as sibling JSON files (`biodino_edge_results.json`, `biodino_companion_int8.onnx`, etc.) so both pipelines and the Android app reference the same quantized artifact. Documentation lives in parallel tracks — formal papers/LaTeX under `docs_and_papers` and a living Obsidian vault under `obsidian_notes` — both citing the same OKF datapackage metadata (`datapackage.json`).
