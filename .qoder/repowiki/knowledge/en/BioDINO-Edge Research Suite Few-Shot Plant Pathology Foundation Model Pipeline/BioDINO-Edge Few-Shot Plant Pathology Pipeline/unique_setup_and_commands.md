Each orchestration script bootstraps itself by prepending its parent directory and the project root to `sys.path` (detecting `plantvillage/` to locate the repo root), then expects dataset directories at `<project_root>/plantvillage` and `<project_root>/plantdoc`. Results are written to `<project_root>/biodino_edge_results.json` (or `_hierarchical_results.json`). The notebook sets `MASTER_SEED = 42` and auto-detects CUDA/MPS/CPU devices before running the full 5-section pipeline.
