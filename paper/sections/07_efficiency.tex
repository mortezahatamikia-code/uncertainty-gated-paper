\subsection{Edge Hardware Latency and Memory Footprint}
\label{sec:edge_hardware}
Table~\ref{tab:device_spec} summarizes the physical testbed configuration, while Tables~\ref{tab:device_perf} and~\ref{tab:adaptation_breakdown} report measured on-device latency, memory consumption, and closed-form adaptation profiling on the handset. Latency is timed over 100 iterations after 10 warm-up passes, memory is tracked via process PSS, and linear algebra is timed following a 60\,s cool-down at stable thermal status (status~2). Note that the 18.0\% fast-exit fraction in Table~\ref{tab:device_perf} is measured on the fixed 11-image device evaluation set (one leaf per target class). The 14.0\% reported in Section~\ref{sec:calibration} instead represents the 30-episode mean over the full PlantVillage query stream.

As broken down in Table~\ref{tab:adaptation_breakdown}, offline adaptation complexity is dominated by support feature extraction ($O(N(C_{\text{dino}}+C_{\text{bio}}))$), whereas the linear algebra operations cost little: empirical scatter estimation ($O(Nd^2)$), Frobenius Ledoit--Wolf shrinkage ($O(Nd)$), and Cholesky inversion ($O(d^3/3)$) execute in pure Java (EJML) in 533.99\,ms without requiring GPU offloading or gradient backpropagation.

On the physical handset, Tier-1 executes in 59.78\,ms ($\approx$16.7\,FPS) and a fully escalated Tier-2 query costs 164.52\,ms end-to-end ($\approx$6.1\,FPS), with the BioCLIP encoder adding 104.74\,ms to the cached Tier-1 pass. Weighting these execution paths by the 14.0\% full-stream fast-exit fraction yields a mean cascaded latency of 149.84\,ms ($\approx$6.7\,FPS, Table~\ref{tab:tier_routing}). Under a 600\,s sustained soak, throughput settles to 4.26\,FPS as the SoC reaches thermal status~3, indicating that 16.7\,FPS represents a cool-start burst rate. In deployment, the gate's role is therefore to decide where latency is spent rather than to raise accuracy: the fast-exited subset is classified at 99.69\% accuracy with a 0.25\% false-negative rate (Section~\ref{sec:calibration}), while only ambiguous queries pay the extra 104.74\,ms BioCLIP pass. Peak process memory is 497.45\,MB PSS (385.02\,MB native heap), dominated by the ONNX Runtime execution arena, while the standalone Android application (APK) occupies $\approx$22.8\,MB and operates entirely offline.
